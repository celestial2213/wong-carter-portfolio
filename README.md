This repository contains the static e-portfolio site for Wong Carter.

How to add or replace images
1. In the GitHub repo go to the assets/images/ folder (create it if it does not exist).
2. Click Add file → Upload files and drag your image files (e.g., profile.jpg, project1.jpg).
3. Commit the change.

Image recommendations
- Profile: 400x400 (rounded)
- Hero/project: 1200x800
- Thumbnails: 400x300

How to replace the CV PDF
1. Upload your final PDF file and name it assets/files/Wong_Carter_CV.pdf.
2. The "Download CV" buttons on the site point to that path.

Enable GitHub Pages (if the site is not visible automatically)
1. Go to the repository Settings → Pages.
2. Under "Source" select the branch "main" and folder "/ (root)" and Save.
3. Wait a minute and the site will be available at: https://celestial2213.github.io/wong-carter-portfolio/

Edit text on the site
- Use the GitHub web UI: open a file (e.g., index.html) and click the pencil icon to edit, then commit.
- Or clone the repo locally: git clone https://github.com/celestial2213/wong-carter-portfolio.git
