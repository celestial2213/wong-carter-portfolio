# Wong Carter E‑Portfolio

Public GitHub Pages portfolio: `https://celestial2213.github.io/wong-carter-portfolio/`

## Replace the CV PDF

The current CV file in the repository is only a placeholder and cannot be opened as a real PDF. Upload the actual PDF through GitHub:

1. Open the repository and go to `assets/files/`.
2. Delete the existing `Wong_Carter_CV.pdf` placeholder.
3. Choose **Add file → Upload files**.
4. Upload the real file named exactly `WongCarter_CV.pdf`.
5. Commit the change to the `main` branch.

The Download CV button already points to `assets/files/WongCarter_CV.pdf`.

## Add images later

Images are not currently used on the website. If you add them later, place them in `assets/images/` and update the relevant HTML page.

## Enable GitHub Pages

In **Settings → Pages**, choose the `main` branch and `/ (root)` folder, then save.
